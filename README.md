# AIdmin

Plataforma que administra una pyme mediante agentes de IA autonomos (CEO, Marketing,
Finanzas, Producto, Desarrollo), coordinados entre si, con trazabilidad completa y
controles humanos obligatorios en todo lo irreversible (dinero y marca publica).
